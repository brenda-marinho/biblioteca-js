# Controle para Biblioteca em JS

## Sobre o projeto
Projeto desenvolvido para o Mini-Projeto Avaliativo (Módulo 01 - Semana 06) do curso Front-End Angular. Trata-se de uma aplicação em JavaScript via terminal para gerenciamento do acervo de uma biblioteca.

## Objetivo
Praticar os principais conceitos do Módulo 01:
- Variáveis (`let`, `const`)
- Estruturas de controle/repetição (`switch-case`, `while`)
- Métodos de Arrays (`forEach`, `find`, `filter`, `reduce`)
- Programação Orientada a Objetos (Classes, `constructor`)
- Modularização em JavaScript (ES Modules: `import` / `export`)

## Como executar
1. Clone o repositório ou baixe os arquivos.
2. No terminal da pasta do projeto, instale a dependência necessária:
   prompt-sync
   npm install
